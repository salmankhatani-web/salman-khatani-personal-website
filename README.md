# Dr. Salman Ahmed Khatani — Personal website

Independent personal website for Dr. Salman Ahmed Khatani, Pakistani futurist and academic working in **Futures Studies and Foresight**, Futures Literacy and responsible AI. This repository does not modify Fiker Futures Academy.

## Website
GitHub Pages URL (once enabled and successfully deployed): https://salmankhatani-web.github.io/salman-khatani-personal-website/

## Current edition
This is a **photo-free edition**, as requested. It uses lightweight typographic and gradient-based brand visuals; no video or image uploads are required. Original photographs may be added in a later revision if desired.

## Deployment
Go to repository **Settings → Pages → Build and deployment → Source: GitHub Actions** if not enabled. Pushes to main run `.github/workflows/deploy.yml` to validate the website and deploy it. View status under Actions.

## Search discoverability
The site contains title and description metadata, a canonical URL, Open Graph tags, robots.txt and sitemap.xml. These are technical foundations, not a promise of rankings or AI citations. Connect the published Pages URL to Search Console / Bing Webmaster Tools with the site owner. Expand research and media entries only with verified public links.

## Public-content care
Do not add unconsented identifying photographs of children or private student reports. Keep course alumni counts separate from formal society membership. Avoid claiming the book is open access without a verified authorized edition.
